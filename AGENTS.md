# AGENTS.md

**project-alpha** (working name): roguelite + deckbuilding + RPG in grimdark dark fantasy, pixel art, Phaser 4, web first (Electron and Android only at the end of Beta). Structure inspired by Darkest Dungeon and Slay the Spire; gothic-military horror tone, without copying names or symbols from other works.

**Language:** English for all repository content (docs, code, comments, keys, commits). Portuguese (PT-BR) appears only as in-game localization in `src/i18n/`; English is the default locale.

## Start of every session

1. Load the skills `karpathy-guidelines` and `caveman`.
2. Read `PLAN.md` → section **Current status** (phase, group, next step).
3. Read the rules in `.claude/rules/` that touch the task.

## Mandatory references

- **Pixel art:** skill `.claude/skills/pixel-logic/` and `docs/books/pixel-logic.md` before creating, generating or reviewing any visual asset.
- **Game design:** skill `.claude/skills/art-of-game-design/` and `docs/books/art-of-game-design.md` before creating or changing a mechanic, card, class, enemy or economy.
- **Phaser 4:** official skills in `.claude/skills/` (`scenes`, `sprites-and-images`, `v4-new-features`, ...). Never apply Phaser 3 patterns.

## Workflow

1. Take the next micro-task from `PLAN.md`; `src/core/` logic is test-first.
2. Validate: `bun run lint`, `bun run lint:md`, `bun run typecheck`, and the affected test (`bun test <file>`).
3. Micro-commit with Conventional Commits (English) for each micro-task; mark `[x]` in `PLAN.md`.
4. End of group: `bun run ci` green → `bun run release` (push to `main` + GitHub release). Update **Current status**.
5. Convention, command or architecture changed: update this file, the ADR and `CHANGELOG.md` (generated by git-cliff).

## Good practices

- Bun for everything; exact, stable versions; new dependencies only with the developer's approval.
- Deterministic core: seeded RNG; no `Math.random` or `Date` in `src/core/`.
- Balancing numbers in `src/data/`; player-facing text in `src/i18n/` (EN default, PT-BR).
- Paid generation (PixelLab, ElevenLabs) only after approval of the list and cost.
- Not sure? Ask. Do not invent data; mark it "not verified".
- Parallel agents: the coordinator (main session) delegates to three fixed agents (Opus review, Sonnet code, Haiku text/i18n/tests/simulations), integrates and commits. No worktrees unless explicitly requested.
