# Rite sweep simulation (2026-10-26)

Greedy bot (`chooseBotCommand`), two acts (`--acts 2`), seed 1. Rite effects from `applyRite` (GDD §13.3). Commands: `bun run sim -- --runs 200 --seed 1 --acts 2 --rite N` for N = 0..10, and `--runs 1000` for Rites 1–3 and 8–10. Raw outputs are in the session scratchpad, not the repo.

## Change applied

Tweak 1 from the first report: Rite 2 (common enemies deal more damage) goes from +15% to +7.5%.

- `src/data/rites.ts`: `commonDamageMul` 1.15 → 1.075.
- `tests/unit/rites.test.ts`: test name updated to +7.5%. The assertion reads `RITES.commonDamageMul`, so it follows the data.
- `src/i18n/en.ts` and `pt-BR.ts`: `rite.2` text updated to 7.5% (PT-BR "7,5%").
- `docs/gdd.md` §13.3 row 2 marked ⚖ and tweaked.
- Rite 3 (start with 30 gold) left as is.

## Method note: paired runs

The simulator is deterministic on a given code state (a re-run of the same command gives the same figure). Other uncommitted work in the tree changed the outputs between windows. The 1000-run baseline was therefore re-run back to back with the tweaked set, and Rite 1 (which does not use the changed multiplier) matches exactly in the pair (25.1 both). The 200-run sweep was also run as a before/after pair in one command. Figures from earlier windows are not compared here.

## Flags after the change

Steepness limit: 8 points in one step. Monotonic: win % must not stay flat or rise.

## Proposed follow-up (not applied)

1. Rite 8 (every enemy starts combat with 1 Might) is now the steep step: -10.5 points at 200 runs. The effect is a single Might per enemy, so halving it is not possible. Options to test, one at a time, each with 200 runs and then 1000 before accepting: (a) apply the Might to non-elite enemies only; (b) give the Might on the enemy's second action instead of at combat start. Pick one with the developer.
2. Rites 8–10 win at about 6% against a 25–45% two-act target. The ladder's top half is too hard overall, not only at Rite 8. This is a separate question from the Rite 2 tweak and needs a decision on the target for late Rites.
3. Rite 3 (start with 30 gold) is a relief rule, so its flatness was accepted by design earlier; it now decreases.

## Caveats

- Greedy bot, not a human player. Absolute win rates do not predict player win rates.
- One seed (1). Another seed moves each Rite's value by about 2 points at 200 runs.
- Act 3 is in progress in the tree. These sweeps use `--acts 2`, so Act 3 does not affect them.
- Other uncommitted changes in the tree moved results between windows. The paired runs above are the valid comparison.
