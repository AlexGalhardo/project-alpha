## Where the game is

- **Content:** 3 acts × 10 rounds, 3 bosses (Bell-Maw, Gilded Penitent, Rift Mother with 3 phases and an epilogue), 30 enemies, 6 elites, 55 cards, 8 equipment items, 12 events, treasure, camp, shop, rest, Sanctum between acts, Legacy skill tree (Embers), Rites 0–10, auto battle and speed 1x/2x/3x.
- **Rules added today:** visible enrage from combat turn 10 (+1 Might per enemy per turn, applied at the start of the player turn so intents include it), turn cap 30, Vanguard (a non-tank in rank 1 gains 4 Block per turn and can play its cards from any rank), enemy damage ×1.25, intents projected through the enemy phase (what is shown equals what happens, P3 tests across 3 acts).
- **Presentation:** 1920×1080 internal canvas, `Scale.FIT`, camera zoom 3 over the 640×360 layout (ADR 0015), self-hosted Roboto, native 3× pixel art for every hero, enemy, boss and card, 1920×1080 composed backgrounds, card fly, lunge, knockback, hit-stop, death fade, keyword chips, unit info panels, incoming damage per hero, act title cards, text size 100/125/150%, keyboard navigation, 24 px tap targets, reset progress.
- **Audio:** music for menu, map, combat per act, boss, final boss, ending; about 40 SFX; all loaded in the background after boot (Title in about 0.6 s).
- **Platforms:** web; Windows portable exe (Electron 45, app icon); Android debug APK (Capacitor 8.5.3, immersive landscape, tested on the `omega-api33` emulator). Every release attaches the web `.tar.gz`, the exe, the APK and `checksums.txt` (ADR 0016).
- **Quality:** 241 unit tests, 44 Playwright tests (4 viewports), `bun run ci` green, 0 console errors over about 20 full QA runs.

## How to resume

1. `bun install --frozen-lockfile`, then `bun node_modules/electron/install.js` once (Bun does not run Electron's postinstall).
2. `bun run ci` must be green; `bunx playwright test` serves its own build on port 4188.
3. With agents editing the tree, never `git stash` or `git rebase --autostash`; release from a scratchpad clone (see `.claude/rules/git-and-release.md`).
